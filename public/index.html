      Kết nối Google OAuth

      Bật đăng nhập bằng Google

      Tính năng đăng nhập Google đã được tích hợp sẵn. Bạn chỉ cần bật 1 trong 2 cách dưới đây là dùng được ngay:

      Cách 1 (Nhanh nhất — qua Supabase Auth):

      Vào Supabase Dashboard → Authentication → Providers → Google, gạt nút Enable Sign in with Google và thêm URL trang web vào Redirect URLs.

      Cách 2 (Dùng trực tiếp Google Client ID):

      Tạo OAuth Client ID tại Google Cloud Console, thêm Origin bên dưới vào Authorized JavaScript origins, rồi điền biến GOOGLE_CLIENT_ID vào .env / Vercel:

      http://localhost:3000
